Lab 2 – Image Processing with OpenCV & PIL


Lab 2 tập trung vào các thao tác xử lý ảnh cơ bản sử dụng Python, OpenCV, PIL, NumPy và atplotlib.  
Notebook bao gồm các bài thực hành về đọc ảnh, lật ảnh, crop ảnh, vẽ hình và thao tác mảng ảnh.

---

Công nghệ sử dụng
- Python
- NumPy
- OpenCV (cv2)
- Pillow (PIL)
- Matplotlib
- Google Colab




Part 1: Xử lý ảnh với OpenCV
- Đọc ảnh (`cv2.imread`)
- Chuyển đổi BGR → RGB
- Lật ảnh (flip theo trục x, y)
- Xoay ảnh (rotate)
- Crop ảnh theo vùng
- Vẽ hình chữ nhật và text lên ảnh

Part 2: Xử lý ảnh với PIL
- Đọc ảnh với `Image.open`
- Chuyển ảnh sang mảng NumPy
- Flip & mirror ảnh
- Crop ảnh bằng `image.crop`
- So sánh ảnh gốc và ảnh đã chỉnh sửa

- lab2.ipynb : Notebook chứa toàn bộ bài thực hành Lab 2
- README.md : Mô tả bài lab

3. Đảm bảo các file ảnh (`baboon.png`, `cat.png`, `lenna.png`) nằm cùng thư mục
